# Данные

Исходные данные — учебный датасет Karpov.courses, в репозиторий не включены.
Чтобы перезапустить ноутбук, положите сюда файлы:

| Файл | Разделитель | Колонки | Строк | Что содержит |
|------|-------------|---------|-------|--------------|
| `Проект_2_groups.csv` | `;` | `id`, `grp` | 74 484 | Распределение пользователей по группам A (контроль) и B (новая механика оплаты) |
| `Проект_2_group_add.csv` | `,` | `id`, `grp` | 92 | Пользователи, присланные в группы позже |
| `Проект_2_active_studs.csv` | `,` | `student_id` | 8 341 | Пользователи, заходившие на платформу в дни эксперимента |
| `Проект_2_checks.csv` | `;` | `student_id`, `rev` | 541 | Оплаты пользователей в дни эксперимента |

В ноутбуке путь к данным задан переменной `way` (путь к папке в JupyterHub курса) — замените его на путь к этой папке.
